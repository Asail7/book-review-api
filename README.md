# Book Review API

RESTful API built using Django REST Framework.

## Features

- JWT Authentication
- User Registration
- Books CRUD
- Reviews CRUD
- Permissions

## Technologies

- Python
- Django
- Django REST Framework
- Simple JWT
- SQLite3

## Run Project

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
